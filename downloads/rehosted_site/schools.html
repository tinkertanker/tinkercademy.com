Programmes for Schools

Programmes
for Schools

We offer a variety of courses for schools. As one of the first vendors for the Code for Fun programme, and the Infocomm Learning Roadmap, we’re well-equipped with the curriculum and experience to deliver first-rate coding training for students of all levels. Read on to find out more about our programmes, or send us an email if you have any questions.

Code for Fun

Code for Fun

Established as one of the earliest Code for Fun initiators under the Code@SG scheme, we've been providing an array of cost-friendly, thorough courses aimed at inculcating coding and making methodologies using Arduino to a broad student base, since 2015.

Infocomm Learning Roadmap

Infocomm Learning Roadmap

In collaboration with IMDA, our industry associates, and educational partners, we provide technology learning programs to Infocomm Media Clubs across primary, secondary, and junior colleges. This is part of the LEARN Roadmap initiative by IMDA.
