# Hero title font trials

Mock-ups exploring replacements for `Oswald` on `.home-hero__title`. Each PNG is the same hero block (1200×360 @ 2x) with the same copy, only the headline font swapped.

The italic span is the last 1–2 words ("into tech.") to preview the bold-roman + italic-serif accent pattern from the inspiration screenshot.

| # | Font | Notes |
|---|------|-------|
| 1 | [`option-1.png`](option-1.png) | **Fraunces** (variable, bold + italic in one family) — modern serif with the SOFT axis. |
| 2 | [`option-2.png`](option-2.png) | **Instrument Serif** — editorial, lighter weight. Beautiful italic. |
| 3 | [`option-3.png`](option-3.png) | **Playfair Display** — classic high-contrast serif. |
| 4 | [`option-4.png`](option-4.png) | **Newsreader** — warm literary serif, very readable. |
| 5 | [`option-5.png`](option-5.png) | **Bricolage Grotesque + Fraunces italic** — sans/serif mix (closest to inspiration). |
| 6 | [`option-6.png`](option-6.png) | **DM Serif Display** — most dramatic, ultra-high contrast. |

Background photo from Framer's CDN was referrer-blocked when rendering from `file://`, so the panels show a flat dark background. Re-render via `node shoot.mjs` after launching the file from a local server if you want the photo back.
