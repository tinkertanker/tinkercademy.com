## Course Overview

<p dir="auto">You can already vibe something up in ChatGPT or Lovable. This public workshop is the step after that: how developers actually keep the work, from prompting to pull request. Four 3-hour sessions. By the end you've shipped a small real thing, from chat to commit, then out to a live URL.</p><p dir="auto">It sits between <a href="/programmes/vibe-coding-for-digital-builders/"><em>Vibe Coding for Digital Builders</em></a> and <a href="/programmes/agentic-engineering-with-claude-code-or-codex/"><em>Agentic Engineering with Claude Code or Codex</em></a>. Not another no-code studio. Not a two-day agent-engineering intensive for working developers. The path from vibe coding to agentic engineering needs this middle step: terminal, Git/GitHub, Claude or Codex as a coding partner, a pull request, and a deploy you can show someone.</p>

## Lesson Outcomes

<p dir="auto">By the end, each participant should be able to:</p><ul dir="auto"><li data-preset-tag="p"><p>Use terminal basics confidently: folders, files, paths, and running a script.</p></li><li data-preset-tag="p"><p>Manage code with Git and GitHub: repo, commit, branch, push, and pull.</p></li><li data-preset-tag="p"><p>Work with Claude or Codex as a coding partner, then review what it writes.</p></li><li data-preset-tag="p"><p>Build a simple app or automation you can run locally.</p></li><li data-preset-tag="p"><p>Open a pull request, review a change, and merge it.</p></li><li data-preset-tag="p"><p>Deploy the app to a live URL.</p></li></ul>

## Curriculum

<p dir="auto">Four sessions. Each is 3 hours. Theme, what we cover, a hands-on block, and a deliverable.</p>

<h3>Session 1: Foundations (terminal, Git, AI coding workflow)</h3><p dir="auto"><strong>Theme</strong>: How developers actually work.</p><p dir="auto"><strong>Cover</strong>: terminal basics (folders, files, paths, <code>cd</code>/<code>ls</code>/<code>pwd</code>/<code>mkdir</code>/<code>touch</code>/<code>cat</code>/<code>rm</code>/<code>cp</code>/<code>mv</code>, env vars, running scripts); editor and project structure (VS Code or Cursor, README, package/project setup); Git basics (repo, commit, branch, status, add, commit, log, diff); AI coding assistant basics (Claude or Codex as a pair programmer, good vs bad prompts, explain code, small changes, review output).</p><p dir="auto"><strong>Hands-on</strong>: create a local project, generate a small script with Claude or Codex, modify it by hand, commit.</p><p dir="auto"><strong>Deliverable</strong>: a local Git repo with a working simple script or app and clean commits.</p>

<h3>Session 2: Building a small app with AI</h3><p dir="auto"><strong>Theme</strong>: From idea to working software.</p><p dir="auto"><strong>Cover</strong>: basic app architecture (frontend, backend, and API as ideas, plus config and dependencies with npm or pip); using AI to plan (architecture, file structure, implementation plan, small steps); debugging with AI (paste errors, find the root cause, make a minimal fix, verify); testing basics (manual checks, a simple automated test, what "done" means).</p><p dir="auto"><strong>Hands-on</strong>: build one of: a simple task tracker, a form plus database, a chatbot-style FAQ, an internal tool dashboard, or a data converter/upload tool.</p><p dir="auto"><strong>Deliverable</strong>: a working local app with README instructions.</p>

<h3>Session 3: GitHub, pull requests, collaboration, review</h3><p dir="auto"><strong>Theme</strong>: Working like a team.</p><p dir="auto"><strong>Cover</strong>: GitHub basics (remote, clone, push, pull, README, issues); branching (main, feature, good commit messages, simple conflicts); pull requests (what a PR is, a good description, code review, AI review of a diff); safety with AI-generated code (no secrets, check dependencies, understand before merge).</p><p dir="auto"><strong>Hands-on</strong>: push to GitHub, open a feature branch, have AI add a feature, open a PR, review someone else's PR, merge.</p><p dir="auto"><strong>Deliverable</strong>: a merged PR with at least one reviewed change.</p>

<h3>Session 4: Deployment, cloud, production basics</h3><p dir="auto"><strong>Theme</strong>: Ship it.</p><p dir="auto"><strong>Cover</strong>: local vs production, hosting, domains, env vars, logs; cloud options at a glance (Vercel or Netlify, Render / Railway / Fly.io, GitHub Pages; AWS / GCP / Azure as an overview only); CI/CD basics (GitHub Actions, auto-deploy on push); production hygiene (secrets, <code>.env</code>, error logs, rollback, monitoring); final polish (README, demo script, limitations, next steps).</p><p dir="auto"><strong>Hands-on</strong>: deploy the app.</p><p dir="auto"><strong>Deliverable</strong>: a live URL.</p>
