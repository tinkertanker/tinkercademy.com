## Course Overview

<p dir="auto">You might have heard of vibe coding, or you might have asked ChatGPT/Gemini/Lovable to build you a widget. Welcome to vibe coding! This is the next step. In this course, you'll learn enough to ship a full web app like a real engineer, to a GitHub repository and hosted on a live URL.</p>

## Lesson Outcomes

<p dir="auto">By the end, you can:</p><ul dir="auto"><li data-preset-tag="p"><p>Use the terminal to navigate your filesystem, install and run command line apps, and manage your project</p></li><li data-preset-tag="p"><p>Understand Git terminology, and make use of Git and GitHub to host your code and run automations</p></li><li data-preset-tag="p"><p>Pair with Claude or Codex, and review what it writes before you keep it</p></li><li data-preset-tag="p"><p>Open a pull request, review a change, and merge it</p></li><li data-preset-tag="p"><p>Build a database-driven web app running on your laptop, then hosted at a live URL</p></li></ul>

## Curriculum

<p dir="auto">Four sessions, three hours each.</p>

<h3>Session 1: Foundations</h3><ul dir="auto"><li data-preset-tag="p"><p>Terminal, Git, and VS Code or Cursor</p></li><li data-preset-tag="p"><p>Write a small script with Claude or Codex, then commit it</p></li></ul>

<h3>Session 2: Build a small app</h3><ul dir="auto"><li data-preset-tag="p"><p>Plan the app, then build it with AI</p></li><li data-preset-tag="p"><p>Debug until it runs, and write a README</p></li></ul>

<h3>Session 3: Pull requests</h3><ul dir="auto"><li data-preset-tag="p"><p>Push to GitHub, open a PR, and review someone else's</p></li><li data-preset-tag="p"><p>Read the diff before you merge</p></li></ul>

<h3>Session 4: Ship it</h3><ul dir="auto"><li data-preset-tag="p"><p>Deploy the app to a live URL</p></li><li data-preset-tag="p"><p>Keep secrets out of the repo</p></li></ul>
