## Course Overview

<p>App development approached from a product and user-experience perspective. Track A suits schools that want students to strengthen design thinking, communication, and computational thinking before deeper coding begins.</p>
<p>Students learn to frame problems, define target users, design user flows, apply accessibility principles, and build high-fidelity interactive prototypes. They test ideas with peers, justify design decisions, and connect app behaviours to programming concepts such as sequence, events, variables, and logic.</p>
<p>By the end of the course, students will have created an interactive app prototype for a real-world problem or user need, supported by user-flow planning, peer feedback, and a short project presentation. No prior coding experience is needed.</p>

## Lesson Outcomes

<ul>
	<li data-preset-tag="p"><p>Use design thinking to frame meaningful app opportunities.</p></li>
	<li data-preset-tag="p"><p>Develop user flows, wireframes, and screen layouts.</p></li>
	<li data-preset-tag="p"><p>Apply accessibility and inclusive-design principles.</p></li>
	<li data-preset-tag="p"><p>Build and test high-fidelity interactive prototypes.</p></li>
	<li data-preset-tag="p"><p>Relate app behaviours to sequence, selection, events, variables, and loops, and build a guided Swift mini-app.</p></li>
	<li data-preset-tag="p"><p>Present design rationale and iteration decisions clearly.</p></li>
</ul>
