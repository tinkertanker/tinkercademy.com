## Course Overview

<p>Authentic app development in a manageable classroom format. Using Swift Playgrounds on iPad, primary, secondary, and junior college students build functional apps with a clear user purpose. It builds naturally on Track A, but no prior coding experience is needed.</p>
<p>Students learn SwiftUI fundamentals — views, layout, state, navigation, data modelling, lists, interactivity, feedback, and debugging — through guided mini-projects, then develop a capstone app while strengthening computational thinking, problem decomposition, and presentation skills.</p>
<p>By the end of the course, students will have created and presented a working Swift app that demonstrates interface design, interaction, navigation, and simple data handling — ready for a school showcase.</p>
<p>The course is offered at two levels, listed separately on the IMDA LEARN Roadmaps application. The format stays the same while project complexity and independence scale with the students:</p>
<ul>
	<li data-preset-tag="p"><p><strong>Primary 4–6:</strong> guided mini-projects covering layouts, buttons, state, navigation, and lists — an accessible first taste of real app development.</p></li>
	<li data-preset-tag="p"><p><strong>Secondary 1–5, JC 1–2:</strong> SwiftUI views, state, navigation, and data modelling, ending in a capstone app presented to the class.</p></li>
</ul>

## Lesson Outcomes

<ul>
	<li data-preset-tag="p"><p>Build SwiftUI interfaces using views, stacks, modifiers, images, and shapes.</p></li>
	<li data-preset-tag="p"><p>Use state and events to make an app respond to user input.</p></li>
	<li data-preset-tag="p"><p>Create multi-screen app experiences with navigation patterns.</p></li>
	<li data-preset-tag="p"><p>Model and display data using arrays, structs, and lists.</p></li>
	<li data-preset-tag="p"><p>Add interactivity, feedback, alerts, and animations.</p></li>
	<li data-preset-tag="p"><p>Test, debug, and iterate on a working Swift app, then present it to an audience.</p></li>
</ul>

## Details

<p><strong>Project</strong></p>
<p>Each student creates and presents a working Swift app demonstrating interaction, design, and simple data handling — a portfolio piece for school showcases, CCA records, and competitions.</p>
<p><strong>Requirements</strong></p>
<ul>
	<li data-preset-tag="p"><p><strong>Computer:</strong> An iPad running iPadOS 17 or later — iPad (6th gen or newer), iPad mini (5th gen or newer), iPad Air (3rd gen or newer), iPad Pro 10.5-inch or 11-inch, or iPad Pro 12.9-inch (2nd gen or newer).</p></li>
	<li data-preset-tag="p"><p><strong>Software:</strong> Swift Playgrounds, free from the App Store. Please install and update it before the first lesson. No AI tools are used.</p></li>
	<li data-preset-tag="p"><p><strong>Hardware:</strong> None required.</p></li>
</ul>
