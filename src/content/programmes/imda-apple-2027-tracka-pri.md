## Course Overview

<p>A friendly, structured introduction to app design for primary school students. Track A is ideal for schools that want students to build app-design confidence before coding: students learn to identify user needs, plan screens, test flows, and present a clickable prototype.</p>
<p>Students explore design thinking, user journeys, visual storytelling, accessibility, and interactive prototyping using Keynote on iPad. They learn to break down app ideas into screens, actions, and user flows, while building confidence in computational thinking.</p>
<p>By the end of the course, each student or team will have created an interactive app prototype that communicates a clear purpose, intended user, and user experience, and presented it to the class. No prior coding experience is needed.</p>

## Lesson Outcomes

<ul>
	<li data-preset-tag="p"><p>Apply design thinking to identify user needs and app opportunities.</p></li>
	<li data-preset-tag="p"><p>Create simple user flows and wireframes for an app idea.</p></li>
	<li data-preset-tag="p"><p>Design accessible app screens with attention to layout, colour, text size, and touch targets.</p></li>
	<li data-preset-tag="p"><p>Build an interactive prototype using Keynote.</p></li>
	<li data-preset-tag="p"><p>Connect app design decisions to introductory Swift coding in Swift Playgrounds.</p></li>
	<li data-preset-tag="p"><p>Present and explain a prototype to an audience.</p></li>
</ul>
