## Course Overview

<p>A friendly, structured introduction to app design for primary, secondary, and junior college students. Track A is ideal for schools that want students to build app-design confidence before deeper coding begins: students learn to identify user needs, plan screens, test flows, and present a clickable prototype.</p>
<p>Students explore design thinking, user journeys, visual storytelling, accessibility, and interactive prototyping using Keynote on iPad. They learn to break down app ideas into screens, actions, and user flows, while building confidence in computational thinking.</p>
<p>By the end of the course, each student or team will have created an interactive app prototype that communicates a clear purpose, intended user, and user experience, and presented it to the class. No prior coding experience is needed.</p>
<p>The course is offered at two levels, listed separately on the IMDA LEARN Roadmaps application. The format stays the same while the depth of design, accessibility, and Swift content scales with the students:</p>
<ul>
	<li data-preset-tag="p"><p><strong>Primary 4–6:</strong> identify user needs, plan screens and user flows, then build and present a clickable app prototype in Keynote on iPad.</p></li>
	<li data-preset-tag="p"><p><strong>Secondary 1–5, JC 1–2:</strong> frame problems, design user flows with accessibility in mind, build a high-fidelity prototype, and connect it to Swift programming concepts.</p></li>
</ul>

## Lesson Outcomes

<ul>
	<li data-preset-tag="p"><p>Apply design thinking to identify user needs and app opportunities.</p></li>
	<li data-preset-tag="p"><p>Create user flows, wireframes, and screen layouts for an app idea.</p></li>
	<li data-preset-tag="p"><p>Apply accessibility and inclusive-design principles to layout, colour, text size, and touch targets.</p></li>
	<li data-preset-tag="p"><p>Build and test an interactive prototype using Keynote.</p></li>
	<li data-preset-tag="p"><p>Connect app design decisions to introductory Swift coding concepts — sequence, events, variables, and logic — in Swift Playgrounds.</p></li>
	<li data-preset-tag="p"><p>Present a prototype and explain the design rationale to an audience.</p></li>
</ul>

## Details

<p><strong>Project</strong></p>
<p>Each student or team creates and presents an interactive app prototype — a portfolio piece for school showcases and competitions.</p>
<p><strong>Requirements</strong></p>
<ul>
	<li data-preset-tag="p"><p><strong>Computer:</strong> An iPad running iPadOS 17 or later — iPad (6th gen or newer), iPad mini (5th gen or newer), iPad Air (3rd gen or newer), iPad Pro 10.5-inch or 11-inch, or iPad Pro 12.9-inch (2nd gen or newer).</p></li>
	<li data-preset-tag="p"><p><strong>Software:</strong> Keynote, Swift Playgrounds, and Freeform, all free from the App Store. Please install and update them before the first lesson. No AI tools are used.</p></li>
	<li data-preset-tag="p"><p><strong>Hardware:</strong> None required.</p></li>
</ul>
