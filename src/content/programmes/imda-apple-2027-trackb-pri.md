## Course Overview

<p>From prototype thinking into functional Swift app development. Using Swift Playgrounds on iPad, primary school students learn how code creates real interaction, navigation, and feedback. It builds naturally on Track A, but no prior coding experience is needed.</p>
<p>Students learn SwiftUI through guided mini-projects covering layouts, buttons, state, navigation, lists, and simple interaction — accessible for young learners while still giving them a genuine taste of app development.</p>
<p>By the end of the course, students will have created and presented a simple Swift app that demonstrates user interaction, visual design, and basic data handling, ready for a school showcase.</p>

## Lesson Outcomes

<ul>
	<li data-preset-tag="p"><p>Build simple SwiftUI views using text, images, shapes, stacks, and modifiers.</p></li>
	<li data-preset-tag="p"><p>Use state to make an app respond to user input.</p></li>
	<li data-preset-tag="p"><p>Create multi-screen app experiences with navigation.</p></li>
	<li data-preset-tag="p"><p>Represent simple data using arrays and structures.</p></li>
	<li data-preset-tag="p"><p>Add interactivity, feedback, and basic animations.</p></li>
	<li data-preset-tag="p"><p>Test, debug, and improve a student-created app.</p></li>
</ul>

## Details

<p><strong>Project</strong></p>
<p>Each student creates and presents a working Swift app demonstrating interaction, design, and simple data handling — ready for a school showcase.</p>
<p><strong>Requirements</strong></p>
<ul>
	<li data-preset-tag="p"><p><strong>Computer:</strong> An iPad running iPadOS 17 or later — iPad (6th gen or newer), iPad mini (5th gen or newer), iPad Air (3rd gen or newer), iPad Pro 10.5-inch or 11-inch, or iPad Pro 12.9-inch (2nd gen or newer).</p></li>
	<li data-preset-tag="p"><p><strong>Software:</strong> Swift Playgrounds, free from the App Store. Please install and update it before the first lesson. No AI tools are used.</p></li>
	<li data-preset-tag="p"><p><strong>Hardware:</strong> None required.</p></li>
</ul>
