## Course Overview

<p>Authentic app development in a manageable classroom format. Using Swift Playgrounds on iPad, secondary and junior college students build functional apps with a clear user purpose. It builds naturally on Track A, but no prior coding experience is needed.</p>
<p>Students learn SwiftUI fundamentals — views, layout, state, navigation, data modelling, lists, interactivity, feedback, and debugging — then develop a capstone app while strengthening computational thinking, problem decomposition, and presentation skills.</p>
<p>By the end of the course, students will have created and presented a working Swift app prototype that demonstrates interface design, interaction, navigation, and simple data handling.</p>

## Lesson Outcomes

<ul>
	<li data-preset-tag="p"><p>Build SwiftUI interfaces using views, stacks, modifiers, images, and shapes.</p></li>
	<li data-preset-tag="p"><p>Use state and events to create responsive app behaviour.</p></li>
	<li data-preset-tag="p"><p>Structure apps using reusable views and navigation patterns.</p></li>
	<li data-preset-tag="p"><p>Model and display data with arrays, structs, and lists.</p></li>
	<li data-preset-tag="p"><p>Add feedback, alerts, animations, and interface polish.</p></li>
	<li data-preset-tag="p"><p>Debug, test, and iterate on a working Swift app.</p></li>
	<li data-preset-tag="p"><p>Present a completed app to an audience.</p></li>
</ul>

## Details

<p><strong>Project</strong></p>
<p>Each student creates and presents a working Swift app — a portfolio piece for school showcases, CCA records, and competitions.</p>

<ul>
	<li data-preset-tag="p"><p><strong>Computer:</strong> An iPad running iPadOS 17 or later — iPad (6th gen or newer), iPad mini (5th gen or newer), iPad Air (3rd gen or newer), iPad Pro 10.5-inch or 11-inch, or iPad Pro 12.9-inch (2nd gen or newer).</p></li>
	<li data-preset-tag="p"><p><strong>Software:</strong> Swift Playgrounds, free from the App Store. Please install and update it before the first lesson. No AI tools are used.</p></li>

</ul>
