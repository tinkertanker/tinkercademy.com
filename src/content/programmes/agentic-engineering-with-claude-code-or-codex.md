## Course Overview

<p dir="auto">AI coding agents can now plan, edit, test, and review software inside a development environment. This two-day workshop teaches you how to direct that work, keep it grounded in a real user need, and decide whether the result is ready to ship.</p><p dir="auto">It's for experienced software developers. Through five practical projects with <strong>Claude Code or Codex</strong>, you'll move from small individual builds to an unfamiliar agentic codebase and a team AI product. Along the way, you'll work with live data, persistent project instructions, reusable capabilities, parallel workflows, external tools, and structured review.</p><p dir="auto">The workshop combines product thinking with hands-on engineering. You'll spend less time typing every line and more time framing the problem, setting useful constraints, inspecting the agent's work, testing assumptions, and improving what you build.</p>

## Lesson Outcomes

<p dir="auto">By the end of this course, you will be able to:</p><ul dir="auto"><li data-preset-tag="p"><p><strong>Frame a useful product before building it.</strong> Identify the user, clarify the problem, control scope, and turn an idea into a plan an agent can act on.</p></li><li data-preset-tag="p"><p><strong>Direct an agent through a real codebase.</strong> Provide durable context and constraints, manage long-running work, and choose when to prompt, plan, intervene, or rewind.</p></li><li data-preset-tag="p"><p><strong>Connect software to the wider world.</strong> Work with live data, AI models, external tools, and reusable agent capabilities while handling configuration and secrets responsibly.</p></li><li data-preset-tag="p"><p><strong>Collaborate safely with people and agents.</strong> Divide work, use branches and worktrees, review pull requests, and set clear goals and limits for parallel or cloud-based agents.</p></li><li data-preset-tag="p"><p><strong>Judge and improve the result.</strong> Reproduce problems, test important assumptions, use evidence to prioritise changes, and polish a working product for its intended audience.</p></li></ul>

## Curriculum

<h3>Setup and foundations</h3><p dir="auto">Prepare Claude Code or Codex, GitHub, and the course tools. We'll look at how coding agents work inside a development environment, what changes when implementation becomes faster, and why the developer remains responsible for the outcome.</p>

<h3>Project 1: From problem to working product</h3><ul dir="auto"><li data-preset-tag="p"><p>Turn a short product brief into a focused application, review the agent's plan, and publish the result.</p></li><li data-preset-tag="p"><p>Practise managing context and recording instructions that should persist across a project.</p></li></ul>

<h3>Project 2: Building with live data</h3><ul dir="auto"><li data-preset-tag="p"><p>Explore a real data source, decide who it could help, and build a small product around it.</p></li><li data-preset-tag="p"><p>Learn how to inspect unfamiliar inputs, recover from an unhelpful direction, and keep the build aligned with its purpose.</p></li></ul>

<h3>Project 3: A deliberately small shared app</h3><ul dir="auto"><li data-preset-tag="p"><p>Scope and deploy a useful app for a specific group, gather feedback, and turn that feedback into clear engineering work.</p></li><li data-preset-tag="p"><p>Use reusable agent capabilities and parallel workflows to make and review improvements safely.</p></li></ul>

<h3>Project 4: Working in an agentic codebase</h3><ul dir="auto"><li data-preset-tag="p"><p>Trace how an existing AI application works, including its model, tools, and external services.</p></li><li data-preset-tag="p"><p>Reproduce a problem, investigate it with coding and browser tools, implement a fix, and review the change through a pull request.</p></li></ul>

<h3>Project 5: Team AI product</h3><ul dir="auto"><li data-preset-tag="p"><p>Define a user, desired outcome, and key assumption, then build one complete slice of an AI-backed product.</p></li><li data-preset-tag="p"><p>Extend the project with one deeper agent-engineering technique, improve the end-to-end experience, and present evidence of what worked.</p></li></ul>

<h3>Presentations and conclusion</h3><p dir="auto">Teams demonstrate their products, explain the problem and engineering choices, and reflect on the evidence, trade-offs, and next steps.</p>
