<ArticleLegacyBlock as="h3" html={"What Is AndroidX Test?"} />

<ArticleLegacyBlock as="p" html={"<a href=\"https://developer.android.com/training/testing/set-up-project\">AndroidX Test</a> is a set of libraries to ease testing on Android. It provides test harnesses and utilities that make writing tests simpler."} />

<ArticleLegacyBlock as="h2" html={"Understanding the Android Test File Structure"} />

<ArticleLegacyBlock as="p" html={"There are a few common rules to writing UI tests:"} />

<ArticleLegacyBlock as="ul" items={["Store all on-device UI tests in the <code>androidTest</code> directory.","Store each test class in the same subdirectory under <code>androidTest</code> as the class under test.","Give each test class the same name as the class under test, but suffixed with the word <strong>Test</strong>."]} />

<ArticleLegacyBlock as="blockquote" html={"Side note: Store off-device UI and unit tests in the <code>test</code> directory instead."} />

<ArticleLegacyBlock as="p" html={"Here’s an example."} />

<ArticleLegacyBlock as="p" html={"I want to test an <strong>ExampleActivity</strong> class. I store it in <code>app/src/main/java/com/example/example-app/ExampleActivity.java</code>."} />

<ArticleLegacyBlock as="p" html={"In this case, I should name my test class <strong>ExampleActivityTest</strong>. I should also store it in <code>app/src/androidTest/java/com/example/example-app/ExampleActivityTest.java</code>."} />

<ArticleLegacyBlock as="p" html={"<a href=\"https://developer.android.com/reference/androidx/test/ext/junit/rules/ActivityScenarioRule\">ActivityScenarioRule</a> builds upon ActivityScenario. It launches an ActivityScenario before each test and cleans up after each test."} />

<ArticleLegacyBlock as="h3" html={"Naming Test Cases"} />

<ArticleLegacyBlock as="p" html={"I named each test case following a structured scheme. It goes like this: <strong>[action/condition]_[expected result]()</strong>."} />

<ArticleLegacyBlock as="p" html={"This naming scheme tells readers the intent of a test case at a glance."} />

<ArticleLegacyBlock as="p" html={"In onClickButton_showsMainActivity(), onClickButton is the action and showsMainActivity<strong> </strong>is the expected result."} />

<ArticleLegacyBlock as="h3" html={"Structuring Code in Test Cases"} />

<ArticleLegacyBlock as="p" html={"The Android team recommends structuring test code based on <a href=\"https://en.wikipedia.org/wiki/Given-When-Then\">Given-When-Then (GWT)</a>."} />

<ArticleLegacyBlock as="p" html={"GWT splits code into three phases:"} />

<ArticleLegacyBlock as="ul" items={["Given: The initial state of the app.","When: The action to carry out. This is like the action used in naming the test case.","Then: The expected result. This is like the expected result used in naming the test case."]} />

<ArticleLegacyBlock as="p" html={"In onClickButton_showsMainActivity(), I separated the three parts with a newline."} />

<ArticleLegacyBlock as="p" html={"There is no <strong>Given</strong> phase in the test."} />

<ArticleLegacyBlock as="p" html={"<code>onView(...)</code> occurs during the <strong>When </strong>phase."} />

<ArticleLegacyBlock as="p" html={"<code>intended(...)</code> occurs during the <strong>Then</strong> phase."} />

<ArticleLegacyBlock as="h3" html={"Performing ViewActions"} />

<ArticleLegacyBlock as="p" html={"Espresso provides ViewActions that perform actions like clicks, typing, and scrolls on Views."} />

<ArticleLegacyBlock as="p" html={"I used <code>perform(...)</code> and <code>click()</code> to click on the Button in IntroductionActivity."} />

<ArticleLegacyBlock as="h3" html={"Verifying Intents"} />

<ArticleLegacyBlock as="p" html={"To verify that the app launches the correct Intent when clicking the Button, the test has to do two things:"} />

<ArticleLegacyBlock as="ol" items={["Capture the launched Intent","Check that the Intent has the MainActivity as the component"]} />

<ArticleLegacyBlock as="p" html={"First, I used the <a href=\"https://developer.android.com/training/testing/espresso/intents\">Espresso-Intents</a> extension to capture Intents. It lives in the <code>androidx.test.espresso:espresso-intents</code> dependency."} />

<ArticleEmbed provider="github-gist" href={"https://gist.github.com/zwliew/93fb07bbb00fd8f73a0b67a9ec57ed48"} title={"IntroductionActivityTest.java"} description={"GitHub Gist: instantly share code, notes, and snippets."} captionHtml={"The pre-test and post-test hooks for IntroductionActivityTest"} />

<ArticleLegacyBlock as="p" html={"I set up pre-test and post-test hooks using the <a href=\"http://junit.sourceforge.net/javadoc/org/junit/Before.html\">Before</a> and <a href=\"http://junit.sourceforge.net/javadoc/org/junit/After.html\">After</a> JUnit annotations."} />

<ArticleLegacyBlock as="p" html={"The pre-test hook initialises the Intent captor to capture launched Intents."} />

<ArticleLegacyBlock as="p" html={"The post-test hook releases the Intent captor for garbage collection."} />

<ArticleLegacyBlock as="blockquote" html={"Note: An <a href=\"https://developer.android.com/reference/android/support/test/espresso/intent/rule/IntentsTestRule\">IntentsTestRule</a> can automate initialisation and release for each test."} />

<ArticleLegacyBlock as="blockquote" html={"But IntentsTestRule also launches the Activity under test. This conflicts with the ActivityScenarioRule that I’ve set up."} />

<ArticleLegacyBlock as="p" html={"Next, I used the <code>intended()</code> and <code>hasComponent()</code> methods to verify the captured Intent."} />

<ArticleEmbed provider="github-gist" href={"https://gist.github.com/zwliew/2646de684f0354e1f503b107dc02b059"} title={"IntroductionActivityTest.java"} description={"GitHub Gist: instantly share code, notes, and snippets."} captionHtml={"The test case verifies the Intent on line 7"} />
